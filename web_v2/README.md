# 웹 화면 v2 (실무용)

`web/`의 첫 화면을 그대로 두고, 팀 피드백을 반영해 복제한 화면이다. 계산 코드(`web/bridge.py`, `nesting/`, `algorithms/`)는
두 화면이 같이 쓰므로 수치는 똑같고, 화면 구성과 문구만 다르다.

| 주소 | 폴더 | 성격 |
|---|---|---|
| https://taaez.github.io/SheetNest/ | `web/` | 알고리즘 비교 중심 (첫 화면, 그대로 유지) |
| https://taaez.github.io/SheetNest/v2/ | `web_v2/` | 실무용: 필요한 원판 길이를 먼저 보여 줌 |

## 첫 화면과 다른 점

| 피드백 | v2에서 바꾼 것 |
|---|---|
| 실무자가 볼 결론(원단 길이) | 결과 맨 위에 결론 카드: 필요한 원판 길이, 이론상 최소와의 차이, 버려지는 비율, 가장 빠른 방법, 방법 사이 길이 차이 |
| 실제 길이로 보기 | "실제 원판 폭" 칸. 적으면 도면 단위를 실제 길이(m, cm)로 바꾸고, 내려받는 SVG와 DXF도 실제 크기(mm)로 만든다 |
| 검증 빼기 | 비교표의 검증 칸을 없애고 결론 카드에 한 줄로 남김. 실패한 방법만 표에 빨간 표시 |
| 계산량 | 비교표에서 빼서 "계산량 자세히"(접힘)로 옮김 |
| 내 도면 올리기 | 실무에 필요한 기능이라 유지. 접힌 채로 두고 안내 문구를 쉽게 고침 |
| 멘트 | 제목, 단계 번호(1 도면 고르기, 2 계산하기, 3 결과), 방법별 한 줄 설명, 표 머리글을 쉬운 말로 |
| 큰 입력 | 계산 중 경과 시간 표시, 멈추기 단추, 오래 걸리는 도면(gardeyn2~9)에 표시 |

## 내 PC에서 열기

```bash
python tools/build_web.py --serve
```

http://localhost:8000/v2/ 를 연다. 첫 화면은 http://localhost:8000/ 에 그대로 있다.

## 고칠 때

- 이 폴더만 고친다. `web/`은 건드리지 않는다(`tests/test_web_bridge.py`가 두 화면이 각자 폴더 그대로 배포되는지 검사한다).
- 방법 설명 문장은 `app.js`의 `METHOD_DESC`, 오래 걸리는 도면 목록은 `SLOW`에 있다.
- 멈추기는 Python 계산을 중간에 끊을 수 없어서 작업자(Web Worker)를 끝내고 새로 띄운 뒤 같은 도면을 다시 불러온다. 몇 초 걸린다.
