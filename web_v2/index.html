SheetNest

조각과 원판 폭을 정하면 조각을 겹치지 않게 배치하고, 원판이 얼마나 필요한지 알려 줍니다. 같은 배치를 세 가지 계산 방법(삼각법, NFP, 래스터)으로 구해 속도도 비교합니다.

Python 실행 환경을 불러오는 중

1. 도면 고르기

적으면 필요한 길이를 실제 길이로 보여 주고, 내려받는 도면도 실제 크기(mm)로 만듭니다.

내 도면 올리기

원판 폭을 비워 두면 도면 안의 원판 사각형(DXF는 SHEET 레이어, SVG는 id가 sheet인 사각형)에서 폭을 읽습니다. 처음 DXF나 SVG를 올릴 때는 도면 읽기 도구를 내려받느라 몇 초 더 걸립니다.

2. 계산하기

계산은 서버 없이 이 브라우저 안에서 합니다. 시간은 PC에서 직접 잰 보고서 값보다 2배 안팎 느리게 나옵니다.

3. 결과

세 방법 비교

가능 위치 계산(여기에 놓으면 겹치는지 판정하는 부분) 그 밖의 처리. 막대 길이는 가장 오래 걸린 방법에 맞췄습니다.

계산량 자세히

같은 배치를 구하려고 각 방법이 몇 번 계산했는지입니다. NFP 재사용이 많을수록 같은 모양 쌍의 계산을 다시 하지 않은 것입니다.

배치 그림

세 방법은 같은 조각을 같은 순서로 놓고, 놓을 자리를 고르는 규칙도 같습니다. 다른 것은 겹치는지 계산하는 방법뿐입니다. 모든 그림은 같은 축척이라 오른쪽 끝이 짧을수록 원판을 덜 쓴 것입니다.
