# 실험

## 실험 규칙

| 실험 | 확인할 것 | 스크립트 |
|---|---|---|
| 0. 병목 확인 | 입력, 순서(A), 위치 계산(B), 결과 생성(C), 검증의 단계별 시간이 N에 따라 어떻게 느는가 | 실험 2와 함께 기록 |
| 1. 격자 간격 | rows 100, 200, 400에 따른 삼각법과 래스터의 품질과 시간 | `tools/exp1_rows.py` |
| 2. 복제 | 수량을 늘릴 때 시간 증가율 k와 순위 역전 | `tools/exp2_scaling.py` |
| 3. 실제 인스턴스 전체 | 모양 복잡도와 반복 정도에 따른 순위, 추천 기준 | 예정 |

### 측정
- 같은 컴퓨터에서 잰다. 세 방법 모두 결정적이므로 사용 길이와 활용률은 1회 값을 쓴다.
- 시간은 1회가 10초 미만이면 5회 평균과 표준편차, 10초 이상이면 1회 값이다.
- 실험 3은 실행 한 번에 10분 제한을 둔다. 넘으면 시간 초과로 기록하고, 그 방법은 그 인스턴스의 추천 후보에서 뺀다.

### 복제 실험(실험 2)
- 부품마다 수량을 1, 2, 4, 8배로 늘리고 원판 폭은 그대로 둔다. shirts와 jakobs1은 16배, swim은 8배까지 잰다.
- 시간 ∝ N^k의 k를 두 가지로 구한다. ×1, ×2, ×4 세 점의 로그-로그 회귀와 ×2에서 ×4 구간의 기울기다.
  각각으로 ×8과 ×16을 예측해 실측과의 오차를 적고, 어느 쪽이 더 맞는지 비교한다.
- shirts 계열은 삼각법과 래스터를 rows 400으로도 돌려 rows에 따라 순위가 바뀌는지 본다.

### 추천 기준(실험 3)
- 제한 시간 T 안에 끝난 방법 중 사용 길이가 가장 짧은 방법을 추천한다. 실제 공장에서는 원단 길이가 비용이기 때문이다.
- 시간과 길이는 모두 실측값을 쓴다. 예측식이나 경계값을 데이터에 맞추지 않으므로 과적합이 없다.
- T를 없음, 1초, 10초, 1분, 10분으로 바꿔 가며 인스턴스마다 추천 방법을 구해 T별 추천 표를 만든다. 웹의 제한 시간 선택지와 같다.
- 실행은 한 번에 10분까지만 돌리고 넘으면 시간 초과로 기록한다. 그래서 실험에서 T = 없음은 10분 상한과 같고,
  10분 안에 끝나지 않는 방법(예: gardeyn 계열 일부의 NFP)은 T = 없음에서도 후보에서 빠진다. 이런 인스턴스는 표에 따로 표시한다.
- NFP는 정확한 Bottom-Left 위치를 구하므로 대체로 가장 짧지만 보장은 아니다. 탐욕 배치에서는 한 번 더 왼쪽에 놓는 것이
  전체 길이에 늘 유리하지 않기 때문이다. 실험 2의 복제 입력 14개 중 11개에서 NFP가 가장 짧았고, shirts ×2, swim ×4,
  swim ×8에서는 삼각법이 1.1~2.3% 짧았다. 실험 3에서 NFP가 시간 안에 끝난 인스턴스를 대상으로 이 비율을 다시 센다.
- 지표 (종류별 볼록 조각 수의 합)² ÷ N은 추천에 쓰지 않고, NFP 시간이 왜 길어지는지 설명하는 데 쓴다(특징별 순위 상관).
- 웹은 같은 선택지(없음, 1초, 10초, 1분, 10분)에서 그 안에 끝날 방법 중 길이가 가장 짧을 방법을 결과 전에 추천한다.
  실행 전에는 끝날지를 알 수 없으므로 시간 예측 방식은 웹에서 따로 정한다.
